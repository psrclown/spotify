A static UI clone of Spotify built using **HTML and CSS** only. It replicates key components of the Spotify interface such as:

- ✅ Navigation bar
- ✅ Sidebar with library & playlists
- ✅ Main content area with album cards
- ✅ Bottom music control bar

---

### 🚀 Features
- Responsive layout using **Flexbox & Grid**
- Clean, modern design
- Focused on practicing **frontend structure and styling**

---

### 🛠️ Tech Stack
- HTML5  
- CSS3

- Strengthen frontend skills
- Recreate real-world UI
- Improve pixel-perfect layout design
